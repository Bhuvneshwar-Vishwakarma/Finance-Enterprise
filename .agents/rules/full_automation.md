# Autonomous Mode & Zero-Interruption Rule

- **Full Automation**: Whenever the user gives a command, execute all necessary file modifications, command runs, and verifications autonomously without pausing to ask for manual selections, confirmation, or permission.
- **No Interactive Modals**: Do NOT use `ask_question` or interactive prompt dialogs unless the user explicitly asks to be interviewed. Choose the optimal implementation path independently.
- **End-to-End Delivery**: Complete the implementation, testing, and refinement directly, presenting only the final results.
